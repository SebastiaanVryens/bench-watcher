# Garden Spine, The Bench Watcher
This project is funded by the European Union, in collaberation with the University of Oulu.

We made a 'Bench Watcher' that can detect privatly on how much a bench is occupied, made with only one ESP32 kit.

There are 2 versions:
- One simple without any recognition and only sensing if someone is sitting or something occupies the bench.
- A far more complex version that stores the users/objects location, time how long it is there and calculate the average time.

# Version one
- One ultra sound sensor senses when an object is close for 1 seconds. When an object is sensed, the bird will flaps his wings.
